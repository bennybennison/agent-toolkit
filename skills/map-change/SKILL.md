# Map Change

Use this skill as the Codex-facing mapping and feasibility entrypoint for Agent Toolkit.

## When To Use It

Use this skill when the user asks to:

- find where something belongs in the repo
- identify related files or modules
- assess feasibility or constraints
- compare candidate placement options
- narrow the working set before planning

## Workflow

1. Resolve the scope of the requested change.
2. Search narrowly for the most relevant files, modules, and patterns.
3. Identify candidate placement options and constraints.
4. Capture risks, dependencies, and feasibility notes.
5. Stop at mapping unless the user explicitly asks for a full plan.

## Output Shape

- Relevant files and modules
- Existing patterns to follow
- Candidate placement
- Risks and feasibility notes
- Narrowed working set
