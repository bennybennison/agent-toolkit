# Contract: WireframePlan

## Purpose

`WireframePlan` defines the front-end-first slice to build or validate before
backend completion.

## When To Use

Use `WireframePlan` for:

- `wireframe-outside-in`
- UI-first concept validation
- mocked product slice planning

## Required Sections

- workflow slice
- target screens
- states and transitions
- visible data needs
- validation plan
