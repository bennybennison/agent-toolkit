# Contract: MapReport

## Purpose

`MapReport` captures what was learned during repo mapping and feasibility work.

It should explain:

- what area was inspected
- what existing patterns matter
- where new work could fit
- what risks or constraints were discovered

## When To Use

Use `MapReport` for:

- `map-and-assess`
- feasibility checks before implementation
- handoff from mapping into planning

## Required Sections

- request scope
- relevant areas
- existing patterns
- candidate placement
- risks
- feasibility notes
