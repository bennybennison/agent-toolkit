# Contract: Plan

## Purpose

`Plan` is the structured implementation plan for turning an idea or request into
 staged work.

It should explain:

- what approach was chosen
- why that approach fits
- what milestones exist
- what risks and verification steps are expected

## When To Use

Use `Plan` for:

- `plan-from-idea`
- larger implementation work
- risky changes that benefit from a written path
- handoff between planning and implementation

## Required Sections

- summary
- strategy selection
- affected areas
- milestones
- risks
- verification strategy
