# Contract: SessionSummary

## Purpose

`SessionSummary` captures the current project/session state in a compact,
durable form.

## When To Use

Use `SessionSummary` for:

- session open
- session resume
- session closeout
- “where are we at?” style requests

## Required Sections

- current status
- active or unfinished work
- notable changes
- blockers or risks
