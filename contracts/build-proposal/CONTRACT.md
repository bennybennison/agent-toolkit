# Contract: BuildProposal

## Purpose

`BuildProposal` captures the intended or completed implementation shape for a
change.

It should explain:

- which files changed or are expected to change
- why they changed
- what behavior shifts resulted
- what confidence and known gaps remain

## When To Use

Use `BuildProposal` for:

- `implement-from-plan`
- implementation handoff
- pre-review change summaries

## Required Sections

- scope
- files changed
- behavior changes
- implementation notes
- confidence

## Related Contracts

- `task-brief`
- `plan`
- `verification-report`
