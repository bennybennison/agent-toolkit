# Contract: DiagnosisNote

## Purpose

`DiagnosisNote` captures the state of a bug or failure investigation before or
alongside the repair.

## When To Use

Use `DiagnosisNote` for:

- `repair-and-verify`
- incident triage
- regressions and failing test analysis

## Required Sections

- symptoms
- reproduction status
- affected area
- evidence
- likely causes
- next fix direction
- verification plan
