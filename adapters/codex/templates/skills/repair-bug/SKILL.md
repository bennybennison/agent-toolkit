# Repair Bug

Use this skill as the Codex-facing repair entrypoint for __DISPLAY_NAME__.

## When To Use It

Use this skill when the user asks to:

- diagnose a bug
- trace inconsistent behavior
- repair a broken flow
- investigate a weird operational issue
- move from symptom to likely cause and fix path

## Workflow

1. Define the symptom precisely.
2. Reproduce the issue or state the missing reproduction blocker.
3. Gather the smallest useful evidence.
4. Rank the most plausible causes.
5. Choose the safest repair direction.
6. End with focused verification steps.

## Output Shape

- Symptom summary
- Reproduction status
- Most likely causes
- Recommended repair path
- Verification evidence to gather
